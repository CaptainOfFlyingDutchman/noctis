## 1.0.0

- Initial release of **Noctis**.
- 11 upstream palettes (Lux, Hibernus, Lilac, Noctis, Azureus, Bordo, Obscuro, Sereno, Uva, Viola, Minimus).
- Each palette ships as an Islands theme (2025.3 default look) and a Classic theme.
- Shared editor color schemes covering JS/TS, HTML/CSS, JSON, Markdown, diagnostics, diff, and terminal.
